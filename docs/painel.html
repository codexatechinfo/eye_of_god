/projeto-novo Corrigido: token expirado fazia o FRONTEND mostrar 'API Offline' por engano
Usuário reportou dashboard/massivas vazios com 'API offline' apesar do backend estar rodando. Diagnóstico: token JWT de 12h vencido, e qualquer 401/403 numa rota autenticada caía no mesmo tratamento de erro de rede do HttpClient, sem distinção. authInterceptor agora detecta 401/403, limpa a sessão e redireciona pra /login (?motivo=sessao-expirada). Confirmado ao vivo pelo browser: com token novo, dashboard e massivas carregam dado real (943 registros) — a API nunca esteve offline de fato.
